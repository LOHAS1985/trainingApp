目的: 優先度高のフロントエンド画面（ホーム・トレーニング入力・種目選択）を中心に、バックエンド・インフラ・QA・ドキュメント・リリースまでの全タスクを網羅的に分解する。

前提: 見積は概算。`d` は営業日。チーム規模は 1〜3 名を想定。バックエンドは REST API で実装され、フロントは Vite + React + TypeScript + Tailwind を使用。
